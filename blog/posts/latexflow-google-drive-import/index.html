Google Drive 에서 바로 가져오기 — .gdoc 이 안 열리는 이유와 Picker 경로

By Math System
게시 2026-08-31 20 분읽는 시간

Google Docs 로 쓴 수학 노트를 변환하려고 파일을 내려받았습니다. 그런데 받아진 파일이 이렇게 생겼습니다.

1

미적분_노트.gdoc      1 KB

문서에는 수식이 수십 개 들어 있는데 파일 크기가 1KB 입니다. 이걸 LaTeXFlow Scan 에 끌어다 놓으면 아무 일도 일어나지 않습니다.

파일이 잘못된 게 아닙니다. .gdoc 은 애초에 문서가 아니기 때문입니다.

1. .gdoc 은 문서가 아니라 주소입니다

Google Docs 문서는 구글 서버에 있습니다. 내 컴퓨터에 있는 .gdoc 파일은 그 문서를 가리키는 짧은 링크 조각 입니다. 문서 번호와 열 주소가 적혀 있을 뿐, 본문도 수식도 그 안에 없습니다. 크기가 1KB 언저리인 것도 그래서입니다.

더블클릭하면 브라우저가 열리면서 원래 문서로 이동합니다. 파일을 연 게 아니라 링크를 따라간 것입니다.

그래서 이런 일이 생깁니다.

  • 변환 도구에 끌어다 놓아도 인식되지 않습니다 — 읽을 본문이 없습니다.
  • 이메일로 보내면 받는 사람은 링크만 받습니다.
  • Drive 앱에서 “다운로드” 를 누르면 .gdoc 이 아니라 PDF 가 내려오는 경우가 많습니다.

마지막 항목은 특히 모바일에서 자주 걸립니다. 그쪽 우회 경로는 iPad 에서 Google Docs 수식 변환하기 에 따로 정리해 두었습니다.

정리하면, Google Docs 를 변환하려면 어딘가에서 한 번은 .docx 로 바꿔야 합니다. 그 한 단계를 도구 안에서 처리하는 게 Drive 가져오기 버튼입니다.

2. 버튼이 하는 일 — 세 단계

업로드 카드 맨 위에 있는 Import from Google Drive 버튼을 누르면 순서가 이렇습니다.

① Google 로그인. 파일에 접근할 권한을 받는 단계입니다. 처음 한 번은 동의 화면이 뜹니다.

② 파일 선택 (Picker). 구글이 제공하는 파일 선택 창이 열립니다. 창 제목은 “LaTeXFlow — Choose a Google Doc or .docx file” 입니다. 여기서 변환할 문서를 고릅니다.

③ 자동 변환 후 스캔. 고른 게 Google Docs 문서면, 도구가 구글에 .docx 형식으로 내보내 달라 고 요청해서 그 결과를 받아 옵니다. 이미 .docx 파일이면 그대로 받습니다. 버튼 라벨이 잠깐 Downloading… 으로 바뀌고, 받아지는 즉시 평소의 수식 탐지 화면으로 넘어갑니다.

사용자가 하는 일은 버튼 누르기와 파일 고르기 둘뿐입니다. 다운로드·형식 변환·다시 올리기가 한 번에 처리됩니다.

받아 온 파일은 브라우저 안에서 열립니다. 파일 자체가 이 서비스의 서버로 올라가지는 않습니다. 다만 변환된 수식의 LaTeX 원문과 렌더 이미지 는 인식 품질 개선을 위해 익명으로 수집됩니다 (자세히).

3. 어떤 권한을 쓰나

Drive 가져오기가 요청하는 권한은 drive.file 하나입니다. 이름 그대로 파일 단위 권한입니다.

 범위
도구가 볼 수 있는 것Picker 에서 내가 고른 그 파일 하나
도구가 볼 수 없는 것Drive 의 나머지 파일, 폴더 목록, 다른 문서

Picker 창에서 폴더를 열어 파일 목록을 훑는 것은 구글이 띄운 창 안에서 일어나는 일입니다. 도구는 그 화면을 들여다보지 못하고, 내가 선택 버튼을 누른 파일 하나만 넘겨받습니다.

로그인이 필요한 것도 이 버튼을 쓸 때뿐입니다. .docx 를 끌어다 놓는 경로는 계정이 전혀 필요 없습니다.

4. 동의 화면에서 무엇을 승인하나

처음 버튼을 누르면 구글의 동의 화면이 한 번 뜹니다. 여기서 확인할 것은 두 가지입니다.

① 어떤 앱인가. 화면 위에 앱 이름과 로고가 표시됩니다. 구글 검토를 거친 앱이라 “확인되지 않은 앱” 경고 화면은 나오지 않습니다. 만약 그런 경고가 보인다면 다른 사이트에 있는 것이니 주소를 확인해 보세요.

② 무엇을 허용하는가. 요청 항목은 파일 단위 접근 한 줄입니다. Drive 전체를 보겠다는 항목이나, 파일을 지우겠다는 항목은 없습니다. 목록이 이보다 길게 나온다면 그 화면은 이 도구의 것이 아닙니다.

동의는 계정에 기억되므로 매번 뜨지는 않습니다. 다음부터는 버튼을 누르면 곧장 파일 선택 창으로 넘어갑니다.

4-1. 나중에 권한을 거두는 법

한 번 승인한 뒤에도 언제든 철회할 수 있습니다. 도구를 거치지 않고 구글 쪽에서 직접 하는 방식입니다.

  1. Google 계정 에 접속합니다.
  2. 보안 → Google 계정으로 로그인 (또는 타사 앱 및 서비스와의 연결) 로 들어갑니다.
  3. 목록에서 해당 앱을 골라 액세스 권한 삭제 를 누릅니다.

철회하면 다음에 버튼을 누를 때 동의 화면이 다시 뜹니다. 그 사이에 변환한 결과나 내려받은 파일에는 영향이 없습니다.

권한을 거두더라도 끌어다 놓기 경로는 그대로 씁니다. 그쪽은 계정과 무관하게 동작합니다.

4-2. 회사·학교 계정이라면

조직에서 관리하는 계정은 관리자가 외부 앱 연결을 막아 둔 경우가 있습니다. 이때는 동의 화면 대신 관리자에게 문의하라는 안내가 뜹니다. 승인을 기다리기 곤란하다면 문서를 개인 계정 Drive 로 사본 저장하거나, 8절의 내보내기 경로를 쓰시면 됩니다.

5. Picker 에 뜨는 형식과 실제로 읽히는 형식

Picker 목록에는 네 가지 형식이 보입니다.

형식Picker 에 뜨나도구가 읽나
Google Docs 문서✅✅ .docx 로 내보내 읽음
.docx✅✅ 그대로 읽음
.odt (오픈오피스)✅❌
.rtf✅❌

뒤의 둘은 목록에 뜨지만 읽히지 않습니다. 골라도 다운로드까지는 진행되다가 분석 단계에서 멈추고 실패 메시지가 뜹니다. 도구가 여는 건 .docx 구조뿐이기 때문입니다.

.odt 나 .rtf 문서를 변환하려면 한 단계를 거치면 됩니다.

  • Drive 에서 그 파일을 Google Docs 로 열어 저장하면 Docs 문서가 됩니다. 그다음 Picker 에서 고릅니다.
  • 또는 워드·리브레오피스에서 열어 다른 이름으로 저장 → Word 문서(.docx) 로 바꿉니다.

폴더도 목록에 표시되도록 해 두었습니다. 파일이 폴더 안에 정리돼 있어도 들어가서 고를 수 있습니다.

6. 버튼이 회색이라 눌리지 않을 때

이 버튼은 구글 쪽 스크립트 두 개(로그인용, Picker 용)가 모두 준비돼야 활성화됩니다. 그래서 페이지를 막 열었을 때 잠깐 회색으로 보일 수 있습니다.

  • 몇 초 기다립니다. 대개 이걸로 해결됩니다.
  • 계속 회색이면 새로고침 합니다.
  • 그래도 안 되면 광고 차단기나 확장 프로그램이 구글 스크립트를 막고 있을 수 있습니다. 해당 페이지에서 잠시 꺼 보거나, 아래의 끌어다 놓기 경로를 쓰시면 됩니다.

버튼을 눌렀는데 “Google 서비스를 불러오는 중” 같은 안내가 뜬다면 아직 준비 중이라는 뜻이니 잠시 뒤 다시 누르면 됩니다.

7. 흔한 막힘

Picker 에 파일이 안 보입니다. Picker 는 로그인한 계정의 Drive 만 보여 줍니다. 학교 계정으로 만든 문서를 개인 계정으로 로그인해 찾고 있는 경우가 가장 흔합니다. 그 계정으로 로그인하거나, 문서를 내 Drive 에 사본으로 저장한 뒤 고르세요.

공유받은 문서가 안 보입니다. 같은 이유입니다. 공유 문서함 에 있는 파일이라면 먼저 내 Drive 에 사본을 만들어 두는 편이 확실합니다.

Import failed 메시지가 뜹니다. 파일을 받아 오는 단계에서 막힌 경우입니다. 권한이 없는 문서이거나, 문서가 삭제·이동됐거나, 네트워크가 끊긴 경우입니다. 메시지에 구글이 돌려준 상태 코드가 함께 나오니 그걸 보고 판단하시면 됩니다.

받아 온 파일 이름 뒤에 .docx 가 붙습니다. 정상입니다. Google Docs 문서에는 확장자가 없어서, 내보낸 결과에 .docx 를 붙여 이름을 만듭니다. 원본 Drive 파일 이름은 바뀌지 않습니다.

변환 결과를 Drive 에 다시 저장하고 싶습니다. 지원하지 않습니다. 결과는 내려받기로 나옵니다. drive.file 권한은 도구가 만든 파일에 한해 쓰기가 가능한 범위이지만, 현재 흐름은 읽어 오는 방향만 씁니다. 내려받은 .docx 를 Drive 에 직접 올리시면 됩니다.

8. 버튼을 안 쓰고 하려면

데스크탑에서는 Docs 안에서 직접 내보내는 경로도 짧습니다.

  1. 변환할 문서를 Google Docs 에서 엽니다.
  2. 파일 → 다운로드 → Microsoft Word (.docx) 를 고릅니다.
  3. 받아진 .docx 를 도구의 점선 영역에 끌어다 놓습니다.

로그인도 동의 화면도 없습니다. 문서 하나를 한 번만 변환할 때는 이쪽이 더 빠를 수도 있습니다.

 Drive 가져오기Docs 에서 내보내기
Google 로그인한 번 필요필요 없음 (이미 Docs 에 로그인된 상태)
매 변환 시 단계버튼 → 파일 선택메뉴 3 단계 → 끌어다 놓기
파일이 여러 개일 때유리 — 매번 버튼 한 번문서마다 내보내기 반복
내려받은 파일 관리남지 않음다운로드 폴더에 쌓임

문서 여러 개를 연달아 변환한다면 버튼 쪽이, 한 번만 할 거라면 내보내기 쪽이 편합니다.

9. 가져온 다음에 볼 것

Drive 에서 가져와도 그다음은 끌어다 놓았을 때와 똑같습니다. 화면 위에 이 줄이 뜹니다.

1

Scanned 62 paragraphs · 48 equations found

수식 수가 0 으로 나온다면 가져오기가 실패한 게 아니라 문서 쪽 문제입니다. 원인이 둘 중 하나입니다.

  • 수식이 LaTeX 구분자로 감싸여 있지 않다 → 구분자가 없는 문서 되살리기
  • Docs 의 삽입 → 수식 으로 넣은 수식 개체다 → 수식 개체와 텍스트의 차이

Google Docs 에서 넘어온 문서는 두 번째 경우가 특히 흔합니다. Docs 의 수식 도구로 넣은 식은 .docx 로 내보낼 때도 개체 그대로 넘어가서, 구분자를 붙일 자리가 없습니다.

10. 자주 묻는 질문

변환하면 원본 Google Docs 문서가 바뀌나요. 아닙니다. 도구는 문서를 읽어 오기만 하고, 결과는 새 .docx 파일 로 내려받습니다. Drive 안의 원본은 손대지 않습니다.

여러 문서를 연달아 변환하려면요. 결과를 내려받은 뒤 상단의 Start Over 를 누르면 첫 화면으로 돌아갑니다. 이미 로그인한 상태라 버튼을 다시 누르면 동의 화면 없이 바로 파일 선택 창이 열립니다.

스프레드시트나 슬라이드도 되나요. Picker 에는 문서 형식만 뜨도록 해 두어서 목록에 나오지 않습니다. 시트나 슬라이드 안의 수식을 변환하려면 내용을 Docs 문서로 옮긴 뒤 고르시면 됩니다.

애드온과는 무엇이 다른가요. Google Docs 애드온(Extensions → LatexFlow → Open Equation Panel)은 문서를 열어 둔 채 그 안에서 수식을 바꿉니다. 파일을 주고받는 단계가 없습니다. 웹 도구는 파일을 받아 변환해 새 .docx 를 내놓는 방식이라, 원본을 남겨 두고 결과물만 따로 만들고 싶을 때 맞습니다.

Picker 창이 열리다 말고 닫힙니다. 팝업 차단에 걸린 경우가 대부분입니다. 주소창의 차단 아이콘에서 이 사이트의 팝업을 허용한 뒤 다시 시도해 보세요.

11. 정리

  • .gdoc 은 문서가 아니라 링크 조각이라, 내려받아 끌어다 놓아도 읽을 본문이 없습니다.
  • Import from Google Drive 버튼이 로그인 · 파일 선택 · .docx 변환을 한 번에 처리합니다.
  • 권한은 drive.file — Picker 에서 고른 그 파일 하나 만 넘어갑니다. 끌어다 놓기 경로는 로그인이 아예 필요 없습니다.
  • Picker 에는 .odt · .rtf 도 뜨지만 읽히지 않습니다. Docs 로 한 번 열어 저장하거나 .docx 로 다시 저장하세요.
  • 가져오기가 됐는데 수식이 0 개라면 원인은 구분자 누락이거나 수식 개체입니다.

Google Docs 는 “파일” 처럼 보이지만 파일이 아니라는 점이 대부분 혼란의 출발점입니다. 그 경계를 한 번 이해해 두면, 어느 화면에서 무엇이 막히는지가 훨씬 빨리 보입니다.
