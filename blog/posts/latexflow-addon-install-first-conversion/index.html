설치부터 첫 변환까지 — Marketplace 에서 애드온 받아 수식 하나 바꾸기

By Teolemma
게시 2026-09-13 업데이트 2026-09-08 17 분읽는 시간

문서에 이렇게 적혀 있습니다.

1

원의 넓이는 $\pi r^2$ 이고, $$\int_0^1 x^2\,dx = \frac{1}{3}$$ 입니다.

이걸 백슬래시가 그대로 보이는 상태가 아니라 수식 모양으로 바꾸고 싶습니다. Google Docs 자체 기능으로는 안 됩니다. Docs 의 삽입 → 수식 은 전혀 다른 종류의 개체를 만드는 기능이고, 내가 적어 둔 LaTeX 을 읽어 주지는 않습니다.

이 글은 그 경로를 한 번 끝까지 걷습니다. 설치 → 동의 → 스캔 → 변환. 처음 한 번은 5 분쯤, 그다음부터는 15 초쯤 걸립니다.

1. 지금 문서에 있는 것과 원하는 것

시작하기 전에 두 가지가 맞아야 합니다.

수식이 글자여야 합니다. 키보드로 \pi r^2 라고 친 것이면 글자입니다. 삽입 → 수식 으로 만든 것이면 개체이고, 아래 내용이 하나도 적용되지 않습니다 (8절 참고).

수식이 구분자로 감싸여 있어야 합니다. 감지 기준이 구분자라서, 아무것도 안 붙은 맨 \frac{1}{2} 는 잡히지 않습니다. 읽는 구분자는 넷입니다.

구분자종류
$…$인라인
$$…$$디스플레이
\(…\)인라인
\[…\]디스플레이

다섯 번째로 맨 대괄호 [ … ] 도 선택적으로 읽을 수 있습니다. 챗봇에서 복사한 텍스트용이고 기본은 꺼져 있습니다 — 8절에서 다룹니다.

구분자 넷의 차이와 어느 자리에 무엇을 쓸지는 구분자 네 가지 에 정리해 두었습니다.

2. Marketplace 에서 설치

Google Workspace Marketplace 의 LaTeXFlow 에서 설치합니다. Google Docs 편집기 애드온이라 내 컴퓨터에 뭘 내려받는 게 아니라 Google 계정에 설치됩니다.

3. 첫 실행 — 동의 화면

설치 과정에서 구글의 동의 화면이 뜹니다. 두 페이지 입니다. 한 페이지인 줄 알고 있으면 조금 당황합니다.

1 페이지 는 계정 화면입니다. 이름, 프로필 사진, 이메일 주소가 보입니다. 이메일 권한은 여기서 승인됩니다.

2 페이지 가 권한 요약입니다. 체크박스 세 개 와 Continue 버튼이 있습니다.

“확인되지 않은 앱” 경고 화면은 나오지 않습니다. 구글 검토를 거쳐 게시된 앱입니다.

합쳐서 권한은 넷이고, 각각 무엇에 쓰이는지는 이렇습니다.

권한쓰임
현재 문서만애드온이 열려 있는 그 문서 하나 만 읽고 고칩니다 — 스캔, 이미지 삽입, 되돌리기
화면 표시Docs 안에 메뉴 · 사이드바 · 설정 창을 그립니다
외부 연결서버 요청 하나 — 동의한 경우 수식 한 쌍을 수집 엔드포인트로 보냅니다
이메일 주소수집 경로에서 한 번 읽어 익명 식별자를 만듭니다

첫 줄이 핵심입니다. 문서 권한의 currentonly 형태라, 다른 문서에 접근하는 것이 불가능 합니다. 안 쓰는 게 아니라 못 하는 쪽입니다. Drive 나 다른 파일에 대한 권한은 목록에 아예 없습니다.

4. 사이드바 열기

문서에서 확장 프로그램 → LatexFlow → Open Equation Panel 을 고릅니다.

오른쪽에 사이드바가 열립니다. 창 제목은 LaTeX → Equation 이고, 탭은 Input 과 Scan 둘입니다. 처음 열리는 쪽은 Input 입니다.

맨 처음 열 때는 데이터 수집 동의 오버레이가 사이드바를 덮습니다. 수식의 LaTeX 원문과 렌더 이미지가 익명으로 수집된다는 것, 이메일은 익명 ID 를 만드는 데만 읽히고 그 ID 는 이메일 + salt 의 SHA-256 을 잘라 쓴 값이라는 것, 설정은 LatexFlow → Data Collection Settings 에서 언제든 바꿀 수 있다는 것을 안내합니다.

버튼은 Decline 과 Agree 둘입니다. 어느 쪽을 눌러도 오버레이는 다시 뜨지 않고 선택이 기억됩니다.

여기는 정확히 적어 둘 만합니다. 애드온의 수집은 opt-in 입니다. Decline 을 누르면 바깥으로 나가는 요청 자체가 없습니다. 줄어드는 게 아니라 없습니다. (웹 도구는 반대로 opt-out 입니다.)

5. 문서 스캔

Scan 탭으로 옮겨 🔍 Scan Document 를 누릅니다.

스캔은 문단 · 목록 항목 · 표 셀을 훑어 네 구분자 중 하나로 감싸인 구간을 전부 찾아 카드로 늘어놓습니다. 순서는 문서 순서 그대로입니다. 상태 줄은 이렇게 나옵니다.

1

Found 7 equation(s) — display: 2, inline: 5

카드마다 잡힌 LaTeX 과, 문서에서 실제로 발견된 구분자 배지가 붙습니다 — $$…$$, \[…\], \(…\), $…$ 중 하나이고 번호가 매겨져 있어 문서와 대조하기 쉽습니다.

변환 전에 카드에 할 수 있는 일이 둘입니다.

  • LaTeX 을 클릭 하면 그 자리에서 고칠 수 있습니다. 변환되는 값은 고친 값입니다.
  • 수식이 아니면 Skip 합니다. 금액을 적은 $100 은 여는 구분자처럼 보여 잡히는데, Skip 하면 글자 그대로 남습니다.

6. 수식 하나 변환하기

카드 하나에서 ➕ Insert into Docs 를 누르면 그 수식이 원래 자리에서 렌더된 이미지로 바뀝니다.

목록 전체가 마음에 들면 ⚡ Convert All 로 나머지를 처리합니다. 문서를 뒤에서 앞으로 훑으며 처리하기 때문에, 앞쪽 수식을 바꿔도 뒤쪽 위치가 밀리지 않습니다. ⏹ Stop 은 지금 처리 중인 것 하나까지만 끝내고 멈춥니다.

진행 상황은 이렇게 표시됩니다.

1

5 / 7 converted (1 skipped)

Input 탭은 방향이 반대입니다. 입력창에 LaTeX 을 치고 라이브 프리뷰로 확인한 뒤, 문서에 커서를 두고 ➕ Insert into Docs 를 누릅니다. 한 가지 알아 두실 것 — Input 탭은 어떻게 쓰든 항상 디스플레이로 삽입합니다. 인라인으로 넣고 싶으면 문서에 $…$ 로 적고 Scan 탭을 쓰시는 편이 맞습니다.

7. 변환 뒤 문서에 남는 것

변환된 수식은 이제 문서 안의 이미지 입니다. 그래서 애드온이 없는 사람이 열어도 그대로 보입니다.

원본 LaTeX 이 버려지는 건 아닙니다. 이미지의 대체 텍스트에 들어갑니다. 그래서 되돌리기가 됩니다 — 수식 이미지를 하나 이상 선택하고 Scan 탭의 ↩ Revert to LaTeX 을 누르면 LaTeX 텍스트로 돌아옵니다.

아무것도 선택하지 않으면 Select an equation image in the document first. 가 뜨고, 애드온이 넣은 이미지가 아니면 No LaTeX metadata found. This image was not inserted by this addon. 가 뜹니다.

문서를 크게 변환하기 전에 알아 두실 한계가 하나 있습니다. Scan 탭의 변환 경로는 MathJax 가 수식을 제대로 렌더했는지 확인하지 않습니다. 문법이 틀린 수식이 빨간 에러 이미지 로 경고 없이 박힐 수 있습니다. 에러가 뜨겠거니 하지 마시고 변환된 문서를 눈으로 한 번 훑어 주세요.

8. 하나도 안 잡힐 때

스캔 결과가 이렇게 나오면,

1
2

No equations found.
No $$…$$, \[…\], \(…\) or $…$ equations found in document.

원인은 넷입니다. 확인할 순서대로 적습니다.

① 구분자가 아예 없다. 제일 흔합니다. 수식이 글자로는 있는데 감싸여 있지 않은 경우입니다.

해결은 같은 Scan 탭, 스캔 버튼 위에 있습니다. 문서에서 수식을 선택하거나 그 줄에 커서만 두고 Tag as $…$ 를 누릅니다. 선택 영역이 있으면 그 범위를, 커서만 있으면 문단 전체 를 감쌉니다. ✅ Tagged! 가 뜨면 🔍 Scan Document 를 다시 누릅니다.

이 버튼은 인라인 $…$ 로만 감쌉니다. 디스플레이로 만들려면 $$ 를 직접 쳐 주세요.

② Docs 의 수식 개체다. 삽입 → 수식 으로 만든 식은 글자가 아니라서 스캐너가 아예 보지 못합니다. 어떤 구분자도 소용없고, 시도하면 안 되는 이유가 따로 있습니다. 네이티브 수식이 들어 있는 문단의 텍스트를 읽어 보면 구조가 뭉개진 채로 돌아옵니다. \frac{1}{2} 가 12 로 읽힙니다. 이걸 $$ 로 감싸면 $$12$$ 가 되는데, 문법상 멀쩡한 LaTeX 이라 아무 불평 없이 변환되고, 원래 2분의 1 이던 자리에 12 라고 적힌 이미지가 남습니다. 에러도 없고 결과도 그럴듯해서 놓치기 쉽습니다. 감싸지 마시고 LaTeX 으로 다시 타이핑하세요.

③ 인라인 $…$ 가 줄바꿈으로 끊겼다. 인라인 달러 수식은 한 줄 안에서 열고 닫아야 합니다. 나머지 세 구분자는 해당 없습니다.

④ $$…$$ 가 문단을 넘어갔다. 스캔 단위가 문단 하나라, 여는 $$ 와 닫는 $$ 가 다른 문단에 있으면 짝이 지어지지 않습니다. 디스플레이 수식은 한 문단 안에 두고, 줄을 바꿔야 하면 Shift + Enter 를 쓰세요.

챗봇에서 복사한 수식이 맨 대괄호 — 백슬래시가 떨어진 [\frac{1}{2}] — 로 들어온 경우라면 Also detect [ … ] 를 켜고 다시 스캔합니다. 애드온에서 기본 꺼짐인 이유는, 직접 쓰고 있는 문서의 대괄호는 수식보다 산문일 확률이 높기 때문입니다.

9. 자주 묻는 질문

문서를 공유받는 사람도 애드온이 필요한가요. 아닙니다. 변환된 수식은 이미지라 누가 열어도 그대로 보입니다.

변환한 뒤에 수식을 고치려면요. 이미지를 선택하고 ↩ Revert to LaTeX 으로 원문을 되찾아 고친 뒤 다시 변환하면 됩니다.

iPad 에서도 되나요. iOS Docs 앱에서는 편집기 애드온을 쓸 수 없습니다. iPad 에서는 웹 도구 쪽을 쓰시면 됩니다. 문서를 .docx 로 내보내거나, 도구 안의 Drive 가져오기 버튼을 쓰면 됩니다.

데이터 수집 설정은 어디서 바꾸나요. 확장 프로그램 → LatexFlow → Data Collection Settings 에서 언제든 양방향으로 바꿀 수 있습니다.

변환하는데 다시 스캔하라는 메시지가 떴습니다. 스캔한 뒤 문서가 바뀌어 기록해 둔 위치가 어긋난 경우입니다. 스캔을 다시 돌리면 됩니다.

10. 정리

  1. 수식을 글자로 쓰고 $…$ 또는 $$…$$ 로 감쌉니다.
  2. Marketplace 에서 설치하고 두 페이지짜리 동의 화면을 지납니다.
  3. 확장 프로그램 → LatexFlow → Open Equation Panel, 수집 동의 오버레이에 답합니다.
  4. Scan 탭 → 🔍 Scan Document → 카드를 검토합니다.
  5. 카드마다 ➕ Insert into Docs, 또는 ⚡ Convert All.
  6. 하나도 안 잡히면 구분자를 먼저, 수식 개체를 그다음으로 의심합니다.
