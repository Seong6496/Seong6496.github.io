1b. Description of Service (Web app)

The Web app is a browser-based tool at mathsystem.dev/latexflow/web/ that converts LaTeX expressions inside a .docx file — uploaded directly or imported from Google Drive — into rendered PNG images. Document conversion runs in your browser. What is collected, and how to opt out, is described in the Privacy Policy. The Web app is provided free of charge and has no paid features. The .tex to Word converter is a separate tool, described in Section 1d.
