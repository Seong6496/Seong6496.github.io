같은 수식을 감싸는 방법이 여러 개입니다.

```
$x^2 + y^2 = r^2$
$$x^2 + y^2 = r^2$$
\(x^2 + y^2 = r^2\)
\[x^2 + y^2 = r^2\]
```

넷 다 같은 식을 가리키지만 결과가 같지는 않습니다. 두 개는 문장 안에 들어가고 두 개는 별도 줄로 나갑니다. 출처도 다릅니다 — 둘은 TeX 에서, 둘은 LaTeX 에서 왔습니다.

어느 것을 써야 하는지는 **어디에 쓰느냐** 로 갈립니다. 이 글은 그 기준을 정리합니다.

## 1. 한눈에

| 구분자 | 종류 | 출처 | 예 |
|---|---|---|---|
| `$ … $` | 인라인 | plain TeX | `$a^2+b^2$` |
| `$$ … $$` | 디스플레이 | plain TeX | `$$E = mc^2$$` |
| `\( … \)` | 인라인 | LaTeX | `\(a_i\)` |
| `\[ … \]` | 디스플레이 | LaTeX | `\[\int_a^b f\,dx\]` |

가로축이 둘입니다. **인라인이냐 디스플레이냐**, 그리고 **TeX 표기냐 LaTeX 표기냐.** 순서대로 보겠습니다.

## 2. 인라인과 디스플레이

**인라인** 은 문장 흐름 안에 수식을 넣습니다. 줄 높이를 되도록 건드리지 않으려고 조판이 납작하게 나옵니다.

> 반지름이 $r$ 인 원의 넓이는 $\pi r^2$ 입니다.

**디스플레이** 는 수식을 문단에서 꺼내 가운데 독립된 줄에 놓습니다. 위아래 여백이 붙고, 조판이 넉넉하게 나옵니다.

$$\int_0^1 x^2\,dx = \frac{1}{3}$$

차이가 여백만은 아닙니다. 같은 명령이 다르게 조판됩니다. 합 기호를 보면 분명합니다.

- 인라인 $\sum_{n=1}^{\infty} \frac{1}{n^2}$ — 범위가 시그마 **옆에** 붙습니다.
- 디스플레이:

$$\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}$$

범위가 시그마 **위아래로** 갑니다. 극한 $\lim_{x \to 0}$ 도 같습니다. 인라인에서는 옆에, 디스플레이에서는 아래에 붙습니다.

그래서 선택 기준이 나옵니다.

- 문장 중간에 짧은 기호나 변수 하나 → **인라인**
- 여러 줄이거나, 첨자·분수가 겹겹이거나, 독자가 멈춰서 봐야 하는 식 → **디스플레이**

긴 식을 인라인으로 우겨 넣으면 줄 간격이 들쭉날쭉해지고 첨자가 뭉개집니다. 반대로 변수 하나를 디스플레이로 빼면 문장이 계속 끊깁니다.

## 3. 어디서 온 표기인가

**달러 기호는 TeX 에서 왔습니다.** Donald Knuth 의 plain TeX 에서 `$` 는 수식 모드를 켜고 끄는 스위치입니다. 여는 기호와 닫는 기호가 **같은 글자** 라는 게 특징입니다. `$$` 는 그 확장으로 디스플레이 모드를 엽니다.

**백슬래시 괄호는 LaTeX 이 따로 만든 표기입니다.** LaTeX 은 명령이 백슬래시로 시작하는 체계라, 수식 구분자도 같은 방식으로 맞췄습니다. 여는 쪽 `\(`, `\[` 과 닫는 쪽 `\)`, `\]` 이 **서로 다른 글자** 입니다.

이 차이가 실제로 뭔가를 바꿉니다.

**① 짝이 어긋났을 때 잡히는 정도가 다릅니다.**

`$` 는 여는 것과 닫는 것이 같은 글자라, 하나를 빠뜨리면 그 뒤의 모든 `$` 가 반대 역할을 하게 됩니다. 오류가 나는 자리도 빠뜨린 자리가 아니라 한참 뒤가 됩니다. `\(` `\)` 는 짝이 구분되니 어긋난 자리가 그대로 드러납니다. (이 증상은 [달러 기호 하나 빠뜨렸을 때](/blog/posts/latexflow-unclosed-dollar-sign/) 에서 자세히 다뤘습니다.)

**② LaTeX 문서에서 두 달러는 권장되지 않습니다.**

`.tex` 파일을 쓰신다면 `$$…$$` 대신 `\[…\]` 를 쓰시는 편이 낫습니다. `$$` 는 LaTeX 의 문서 옵션(예: 수식을 왼쪽 정렬하는 `fleqn`)을 무시하고, 앞뒤 세로 간격이 상황에 따라 달라집니다. `amsmath` 문서도 같은 이유로 `\[…\]` 나 `equation` 환경을 권합니다.

**③ 마크다운 계열에서는 달러 기호가 사실상 표준입니다.**

반대로 마크다운·노션·옵시디언·주피터 같은 환경에서는 `$…$` / `$$…$$` 가 가장 널리 통합니다. 이쪽은 LaTeX 문서가 아니라 수식 렌더러를 얹은 마크다운이라 관습이 다릅니다.

## 4. 상황별 권장

| 쓰는 곳 | 권장 | 이유 |
|---|---|---|
| LaTeX 문서 (`.tex`) | `\(…\)` · `\[…\]` | 문서 옵션과 간격이 일관됨 |
| 마크다운 · 노션 · 옵시디언 | `$…$` · `$$…$$` | 이쪽 생태계의 사실상 표준 |
| 워드 · Google Docs 에 적어 두고 변환 | `$…$` · `$$…$$` | 타이핑이 짧고 눈에 잘 띔 |
| 챗봇에게 요청 | `$…$` · `$$…$$` | 복사 경로에서 살아남음 |

마지막 줄에는 별도의 이유가 있습니다. 채팅창의 마크다운 렌더링을 통과하면서 `\(…\)` 는 흔적 없이 사라지는데, 달러 기호는 그대로 살아남습니다. 자세한 내용은 [챗봇에 수식을 요청하는 방법](/blog/posts/chatgpt-math-request-format/) 에 있습니다.

## 5. 구분자와 수식 환경은 다른 것입니다

LaTeX 에는 구분자 말고 **수식 환경** 도 있습니다. 자주 섞여서 이야기되는데 층이 다릅니다.

```latex
\begin{equation}
  E = mc^2
\end{equation}
```

`\[…\]` 은 이것과 거의 같은 일을 합니다. 정확히는 번호가 붙지 않는 `equation*` 과 같습니다.

| 쓰는 법 | 결과 |
|---|---|
| `\[ … \]` | 번호 없는 디스플레이 수식 |
| `equation*` 환경 | 같음 |
| `equation` 환경 | 번호가 붙는 디스플레이 수식 |
| `align` · `gather` 환경 | 여러 줄 수식, 줄마다 번호 |

번호를 달고 본문에서 *"식 (3) 에서 보듯"* 처럼 참조해야 한다면 구분자가 아니라 환경이 필요합니다. 이쪽은 [수식 번호와 eqref](/blog/posts/latex-equation-labels-eqref/) 와 [align 환경](/blog/posts/latex-align-equations/) 에서 따로 다뤘습니다.

**변환 도구 입장에서는 중요한 단서가 하나 있습니다.** 도구는 구분자만 봅니다. 환경은 읽지 않습니다. 그래서 워드 문서 안에

```
\begin{equation} E = mc^2 \end{equation}
```

라고 적어 두면 **감지되지 않습니다.** `\begin` 은 구분자가 아니기 때문입니다. (다만 백슬래시가 있으니 *"수식처럼 보이는 문단"* 후보로는 올라옵니다.) 워드·Docs 문서를 변환할 목적이라면 환경 대신 `$$…$$` 로 감싸 주세요.

번호와 상호 참조가 정말 필요한 문서라면, 애초에 워드가 아니라 LaTeX 으로 쓰시는 편이 맞습니다. 변환 도구는 *이미 있는 문서* 를 보기 좋게 만드는 쪽에 맞춰져 있어서, 수식 번호를 관리해 주지는 않습니다.

## 6. 변환 도구는 넷을 어떻게 처리하나

[LaTeXFlow Scan](/latexflow/web/) 은 네 가지를 모두 읽습니다. 다만 내부 처리가 조금씩 다르고, 그 차이가 화면에 드러납니다.

**두 달러는 언제나 명확합니다.**
`$$` 는 두 글자 짝이라 여는 자리와 닫는 자리가 정해집니다. 판정에 애매함이 없습니다.

**한 달러는 개수가 홀수면 모호해집니다.**
한 문단에 `$` 가 홀수 개면 어디가 여는 자리인지 알 수 없습니다. 이때 도구는 추측하지 않고 **모호성 카드** 를 띄워 사용자에게 넘깁니다.

**백슬래시 괄호는 언제나 명확합니다.**
`\(` 와 `\)` 는 서로 다른 글자라 짝이 자동으로 정해집니다. 그래서 이 두 구분자는 모호성 흐름을 아예 타지 않습니다. 홀수라는 개념 자체가 없습니다.

**겹칠 때는 달러가 우선입니다.**
`$\(x\)$` 처럼 두 표기가 겹쳐 있으면 같은 자리가 두 번 잡힐 수 있습니다. 그래서 백슬래시 괄호 스캐너는 먼저 문단 안의 `$` / `$$` 구간을 계산해 두고, 그 구간과 겹치는 매칭은 건너뜁니다. 결과적으로 한 자리는 한 번만 잡힙니다.

## 7. 다섯 번째 — 대괄호 모드

도구에는 구분자가 하나 더 있습니다.

```
[\lim_{x\to0}\frac{\sin x}{x}]
```

**이건 LaTeX 표기가 아닙니다.** 챗봇 답변을 복사할 때 `\[ … \]` 의 바깥 백슬래시가 떨어져 나가 `[ … ]` 만 남는 일이 잦아서, 그 자리를 복구하려고 만든 장치입니다.

맨 대괄호를 전부 수식으로 보면 오탐이 감당이 안 되니 조건을 답니다. **대괄호 안에 `\`, `^`, `_`, `=` 중 하나라도 있어야** 수식으로 봅니다.

- `[\frac{1}{2}]` → 백슬래시 있음 → 잡힘 ✅
- `[y=2x]` → 등호 있음 → 잡힘 ✅
- `[참고]`, `[1]`, `[표 1]`, `[1번 문제]` → 기호 없음 → 안 잡힘 ✅
- `[1,5]` (구간 표기) → 기호 없음 → **못 잡음** ❌ — `$[1,5]$` 로 직접 감싸야 합니다

중첩도 처리합니다. `[\sqrt{[a+b]}]` 처럼 안쪽에 대괄호가 또 있으면 깊이를 세어 바깥 짝을 찾습니다. 수식 안의 대괄호도 보호합니다 — `$E[X^2]$` 의 `[X^2]` 는 이미 달러 구간 안이라 별도로 잡히지 않습니다.

**알려진 한계가 하나 있습니다.** 대괄호 모드를 켠 상태에서 문서에 진짜 `\[E=mc^2\]` 가 있으면, 대괄호 스캐너가 `[E=mc^2\]` 를 별개 항목으로 한 번 더 잡아 **같은 식이 두 번** 목록에 오를 수 있습니다. 리뷰 화면에서 한쪽을 Skip 하거나 대괄호 모드를 끄면 됩니다.

**기본값이 두 곳에서 다릅니다.**

| | 대괄호 모드 기본값 |
|---|---|
| 웹 도구 | **켜짐** |
| Google Docs 애드온 (*Extensions → LatexFlow → Open Equation Panel*) | **꺼짐** |

웹은 챗봇 답변을 붙여 넣은 `.docx` 가 주로 들어오는 자리라 켜 두었고, 애드온은 이미 Docs 안에서 작성 중인 문서라 대괄호가 산문일 확률이 더 높아 꺼 두었습니다. 어느 쪽이든 체크박스로 바꿀 수 있습니다.

## 8. 자주 걸리는 함정

**가격 표기가 수식으로 잡힙니다.**
`$100` 처럼 달러 기호가 하나만 있으면 여는 구분자처럼 보입니다. 예상된 동작이라, 리뷰 화면에서 Skip 하거나 모호성 카드에서 정리하면 됩니다. 금액이 여러 개인 문서라면 아예 `\$100` 으로 이스케이프해 두는 편이 편합니다.

**디스플레이 수식이 문단을 넘어갑니다.**

```
$$
E = mc^2
$$
```

이렇게 세 줄로 쓰면 문서에서는 문단 세 개입니다. 여는 `$$` 와 닫는 `$$` 가 서로 다른 문단에 있어 짝이 지어지지 않습니다. 한 문단 안에 넣거나, 줄바꿈이 필요하면 문단 나누기 대신 줄 바꾸기(`Shift` + `Enter`)를 씁니다.

**한 달러 수식 안에 줄바꿈이 있습니다.**
애드온 쪽 인라인 패턴은 줄바꿈을 건너뛰지 않습니다. 인라인 수식은 한 줄 안에서 열고 닫아야 합니다.

**여는 것과 닫는 것을 섞어 씁니다.**

```
\(x^2$
```

이런 조합은 어느 쪽으로도 짝이 되지 않습니다. 한 수식은 한 종류로 열고 닫습니다.

## 9. 빠른 선택

- 문장 안에 짧게 → `$…$` (LaTeX 문서라면 `\(…\)`)
- 독립된 줄에 크게 → `$$…$$` (LaTeX 문서라면 `\[…\]`)
- 챗봇에게 요청할 때 → 달러 기호 두 종류만
- 대괄호만 남은 답변을 받았을 때 → 대괄호 모드를 켜고 올려 봅니다

## 10. 자주 묻는 질문

**한 문서에 네 가지를 섞어 써도 되나요.**
됩니다. 스캐너가 각각 독립적으로 돌고 겹침도 정리하므로 섞여 있어도 전부 잡힙니다. 다만 사람이 나중에 읽을 때 헷갈리니 한 문서 안에서는 하나로 통일하시는 편이 낫습니다.

**구분자 없이 그냥 `\frac{1}{2}` 라고 쓰면요.**
잡히지 않습니다. 구분자가 없는 LaTeX 은 평범한 글자로 남습니다. 다만 도구가 *"수식처럼 보이는 문단"* 으로 제안은 해 줍니다 — [구분자가 없는 문서 되살리기](/blog/posts/latexflow-no-delimiter-recovery/) 를 참고하세요.

**수식 편집기로 넣은 식에는 어떤 구분자를 붙여야 하나요.**
어느 것도 소용없습니다. 수식 편집기로 넣은 식은 글자가 아니라 문서 안의 개체라 구분자를 붙일 자리가 없습니다. [수식 개체와 텍스트의 차이](/blog/posts/word-equation-objects-not-text/) 에 다뤄 두었습니다.

**세 달러(`$$$`)나 다른 표기도 있나요.**
표준에는 없습니다. 위의 네 가지와 LaTeX 의 수식 환경(`equation`, `align` 등)이 사실상 전부입니다. 여러 줄 정렬이 필요하면 [align 환경](/blog/posts/latex-align-equations/) 쪽을 보시면 됩니다.

## 11. 정리

- 인라인 두 개(`$…$`, `\(…\)`)와 디스플레이 두 개(`$$…$$`, `\[…\]`) — 축은 이 하나입니다.
- 달러 기호는 TeX, 백슬래시 괄호는 LaTeX 표기입니다. `.tex` 문서에서는 후자를, 마크다운 계열과 변환 워크플로에서는 전자를 씁니다.
- 여는 것과 닫는 것이 같은 글자인지가 짝 어긋남의 난이도를 가릅니다.
- 대괄호 모드는 LaTeX 이 아니라 챗봇 복사 경로의 복구 장치입니다. 웹은 기본 켜짐, 애드온은 기본 꺼짐입니다.
